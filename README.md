# 🛍️️ Stride Store - Modern E-Commerce Web Application

**Stride Store** is a fully functional, responsive, and modern e-commerce web application built using **React**, **Vite**, and **Tailwind CSS**. It delivers a smooth shopping experience with real-time state management, product filtering, dynamic cart and wishlist management, and secure checkout simulation.

---

## 🚀 Live Demo
🔗 **[View Live Demo](https://stride-store-app.vercel.app/#/)**

---

## ✨ Features

- 🔐 **User Authentication**: Secure user registration, login, protected routes, and password reset workflows.
- 🛒 **Shopping Cart Management**: Add, update item quantities, remove products, and clear cart with real-time totals.
- ❤️️ **Wishlist Integration**: Save favorite items with instant add/remove synchronization.
- 📦 **Product Catalog & Details**: Browse products by category, search items, view detailed specifications, and image sliders.
- 💳 **Online & Cash Checkout**: Integrated payment flow supporting Cash on Delivery and online payment integration.
- 📱 **Fully Responsive UI**: Mobile-first design crafted with Tailwind CSS for seamless cross-device compatibility.
- ⚡ **Optimized Performance**: Fast data fetching, mutation caching, and state management using React Query.

---

## 🛠️ Tech Stack & Tools

- **Frontend Framework**: [React.js](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **State Management & Data Fetching**: React Context API & React Query (`@tanstack/react-query`)
- **HTTP Client**: [Axios](https://axios-http.com/)
- **Deployment & Hosting**: [Vercel](https://vercel.com/)

---

## 📁 Project Structure

• **src/Apis/**: API integration endpoints (Cart, Products, Wishlist, Checkout)
• **src/assets/**: Media assets, images, icons, and custom stylesheets
• **src/Components/**: Modular UI components (Navbar, Cart, ProductDetails, etc.)
• **src/Context/**: React Context providers (AuthContext, CounterContext)
• **src/Hooks/**: Custom hooks for React Query mutations and queries
• **src/App.jsx**: Route definitions and application layout
• **src/main.jsx**: Application entry point

## 💻 Getting Started Locally

To run this project on your local machine, follow these steps:

### 1. Clone the Repository
git clone https://github.com/BaherElgobashi/Stride-Store.git
cd Stride-Store

### 2. Install Dependencies
npm install

### 3. Start Development Server
npm run dev

Open `http://localhost:5173` in your browser to view the application.

### 4. Build for Production
npm run build
